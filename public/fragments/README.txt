Silvae literary fragment archive

Every entry includes its author, work title, language, source page and pinned
Wikiquote revision. Follow the source URL for the original attribution, edition
notes, source history and contributors. The "license" field denotes the version
of Creative Commons Attribution-ShareAlike used for the source collection and
presentation: https://creativecommons.org/licenses/by-sa/4.0/

The underlying original excerpts are screened separately using a curated author
allowlist and source metadata. A repository/software license is not treated as
permission for arbitrary modern book text. See docs/daily-fragment-archive.md
and docs/fragment-import-report.json in the Silvae source repository for the
import procedure and limitations. Excerpts are transcribed from their cited
sources; they are not generated or machine-translated.
